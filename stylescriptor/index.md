# StyleScriptor Privacy Policy

_Last updated: May 2026_

## Overview

**StyleScriptor** is a lightweight browser extension that allows users to define, save, and apply custom CSS and JavaScript separately for each domain.

This Privacy Policy explains what data StyleScriptor uses, how it is stored, and how it is handled.

---

## Data Collection

StyleScriptor does **not** collect, sell, share, or transmit personal data to any external server.

StyleScriptor does **not** collect:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication information
- Personal communications
- Location data
- Browsing history
- User activity data
- Website content

---

## Local Storage

StyleScriptor stores the following data locally in the user's browser using Chrome storage:

- User-created custom CSS
- User-created custom JavaScript
- Per-domain enabled or disabled settings

This data is stored only on the user's device and is used only to apply the user's own custom CSS and JavaScript to domains configured by the user.

---

## Domain-Based Customization

StyleScriptor works on a per-domain basis.

When a user saves custom CSS or JavaScript for a specific domain, StyleScriptor loads and applies that saved code only for that domain.

For example, if a user saves custom CSS or JavaScript for `example.com`, StyleScriptor applies that saved code only when the user visits `example.com` and the extension is enabled for that domain.

---

## Custom CSS and JavaScript

All CSS and JavaScript code is created, edited, saved, and managed by the user.

StyleScriptor does not provide, download, or execute remote scripts from external servers.

The extension only applies the custom CSS and JavaScript that the user manually enters into the extension.

---

## Remote Code

StyleScriptor does **not** use remote code.

The extension does not download JavaScript files, CSS files, or executable code from external servers.

---

## Third-Party Data Sharing

StyleScriptor does **not** sell, share, transfer, or disclose user data to third parties.

The extension does not use user data for:

- Advertising
- Analytics
- Tracking
- Profiling
- Creditworthiness evaluation
- Lending purposes
- Any unrelated purpose

---

## User Control

Users have full control over the CSS and JavaScript they create.

Users can:

- Add custom CSS per domain
- Add custom JavaScript per domain
- Enable or disable custom code per domain
- Clear saved custom code
- Stop using the extension at any time

---

## Permissions Explanation

StyleScriptor may request browser permissions required for its core functionality.

### storage

Used to save the user's custom CSS, custom JavaScript, and enabled/disabled settings separately for each domain.

### tabs

Used to detect the active tab's domain so StyleScriptor can load the correct saved settings for that website.

### activeTab

Used to apply the user's custom CSS and JavaScript to the currently active tab when the user chooses to apply changes.

### scripting

Used to inject the user's own custom CSS and JavaScript into the active webpage.

### Host Permissions

Required so users can apply their own custom CSS and JavaScript to the domains they choose to customize.
